# 无人机运行识别模块

依据[GB46750-2025  民用无人驾驶航空器系统运行识别规范](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=56E7666BF313B2F51A747F2BEEE4F896)规范，提供无人机运行识别信号发射与接收模块，满足合规飞行要求。

## 产品列表

| 型号 | 核心特点 |
|:-----|:---------|
| [RID接收模块](01-NP-RID-Receiver.md) | 支持WiFi信标帧、蓝牙5广播信号接收、解析<br />支持MAVLink协议或GB46750协议<br />具备参数设置功能<br />具备OTA升级能力 |
| [RID发射模块](02-NP-RID-Sender.md) | WiFi信标帧、蓝牙5广播信息发射<br />支持PX4、Ardupilot<br />具备网页查看无人机状态功能<br />具备参数设置功能<br />具备虚拟RID模拟功能<br />具备OTA升级功能 |
