# 无人机运行识别模块

依据GB46750-2025规范，提供无人机运行识别信号发射与接收模块，满足合规飞行要求。

## 产品列表

| 型号 | 核心特点 |
|:-----|:---------|
| [RID接收模块](01-NP_RID_Receiver.md) | 支持WiFi信标帧、蓝牙5广播信号接收、解析<br />支持MAVLink协议或GB46750协议<br />具备参数设置功能<br />具备OTA升级能力 |
| [RID发射模块](02-NP_RID_Sender.md) | WiFi信标帧、蓝牙5广播信息发射<br />支持PX4、Ardupilot<br />具备网页查看无人机状态功能<br />具备参数设置功能<br />具备虚拟RID模拟功能<br />具备OTA升级功能 |
